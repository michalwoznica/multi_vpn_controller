# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository instead.

When reporting a vulnerability, please include:

- the affected MVC version;
- a clear description of the issue;
- steps required to reproduce it;
- the expected security impact;
- any relevant logs or command output, with credentials, keys, hostnames, addresses, and other sensitive information removed.

Please avoid including real VPN credentials, private keys, authentication material, or other secrets in reports unless they are strictly necessary to understand the vulnerability.

## Supported versions

Security fixes are provided for the current stable release of Multi VPN Controller.
